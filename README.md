# clawmes

> Hermes Agent for crypto. The biggest open-source AI assistant, now it handles real money.

A crypto-native extension to [Hermes Agent](https://github.com/NousResearch/hermes-agent) — direct access to blockchain protocols, market data, and transaction execution. Python rewrite of the OpenClaw-targeted [`@clawnch/openclaw-crypto`](https://github.com/clawnchdev/openclawnch).

48 tools. 118 commands. 76 services. Runs on Telegram, Discord, Slack, Signal, WhatsApp, iMessage, and LINE.
